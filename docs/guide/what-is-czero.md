# 什么是 CZero

CZero 是一个 Android Root 清理模块，为常见的高频应用提供缓存清理，并涵盖后台压制、空文件夹清理、F2FS 垃圾回收与 fstrim。

模块本身没有常驻服务，由一个极轻量的调度进程按 `config.json` 触发所有任务，配置修改即时生效。日常操作通过原生配套应用 **CZeroX** 完成。

## 它解决什么问题

长期使用后，应用缓存与后台常驻会持续占用存储和内存，手机逐渐变卡、可用空间变少。CZero 在后台按计划自动完成清理与压制，让设备保持干净、流畅，无需手动干预。

## 设计理念

- **无常驻服务** —— 不驻留任何 Java 进程，调度交给一个原生的微型进程，开销趋近于零；清理器用完即退。
- **单一配置源** —— 所有行为集中在一份 `config.json`，无中间派生文件。
- **即时生效** —— 配置变更自动热重载；配置损坏时保留上一份有效任务，绝不中断。
- **原生前端** —— 日常操作通过原生应用 CZeroX 完成，不依赖 WebUI。

## 它把东西放在哪

模块自身与配置都在 `/data/adb/modules/CZero/`，其中 `config.json` 是唯一需要你关心的文件 —— 日常用 CZeroX 编辑即可。清理统计与日志也在这个目录下，卸载模块时一并清除。

清理产生的**回收站**不在模块目录内，而位于内置存储的 `Recycle` 文件夹，被清理的文件在此保留 7 天可恢复，详见[功能详解 · 回收站与恢复](/guide/features#回收站与恢复)。

## 环境要求

- Android 9+（API 28），`arm64-v8a`
- Root 方案：Magisk、KernelSU 或 APatch
- F2FS `/data` 分区（仅 GC 功能需要，其余功能不受影响）

准备好后，前往 [安装与上手](/guide/getting-started)。
