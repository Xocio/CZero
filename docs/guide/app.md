# CZeroX 应用

**CZeroX** 是 CZero 的原生配套应用，采用 Jetpack Compose 构建（Miuix 风格），直接读写模块的 `config.json` 与各份规则 JSON。它是模块唯一的图形化配置前端，无需 WebUI。

## 下载

在[下载页](/download)或 [Releases](https://github.com/Xocio/CZero/releases) 获取最新版 APK。模块与应用建议保持同版本。

## 三个标签页

应用底部分为 **主页 / 存储 / 设置** 三块。

### 主页

- **运行状态** —— 调度进程的运行情况与内存占用；未在运行时可一键重启。
- **清理统计** —— 今日与累计释放的空间，以及各应用清理、空文件夹、压制、垃圾回收的执行次数。点击可进入**清理趋势**页，查看近 7 / 30 天的每日释放量。
- **F2FS 状态** —— 实时的段使用情况。
- **一键操作** —— 立即清理、单应用清理、后台压制、F2FS 垃圾回收、空文件夹清理。执行过程通过通知显示进度与结果，支持超级岛。

### 存储

与清理无关、但同样关乎存储健康的面板：

- **器件寿命** —— 显示 UFS / eMMC 的寿命等级与预留块预警，换算为剩余寿命区间。
- **实时读写速率** —— 当前读写曲线与累计读写量。
- **性能测试** —— 顺序读写、随机读写、数据库事务三类项目，给出综合评分。多轮结果波动过大时会提示重测。
- **器件信息** —— 类型、型号、厂商、固件与容量。

::: tip 寿命数据为只读读取
寿命与器件信息均为只读读取，不会向存储器件写入任何数据。性能测试会实际读写测试文件，结束后自动清理。
:::

### 设置

按分组覆盖 `config.json` 中的每一项，保存后即时生效，无需重启。

| 分组 | 包含 |
|---|---|
| **清理** | 基础清理、GC 清理、后台压制（及其目标应用名单）、空文件夹清理（及白名单）、增强清理、回收站 |
| **规则** | 自定义规则（内置规则 + 规则源）、清理白名单、应用缓存清理 |
| **精细化压制** | 压制开关与能力探测、压制应用名单 |
| **其他** | 日志、应用设置（语言 / 主题等）、备份与恢复 |

## 几个主要页面

### 规则编辑器与规则源

管理自定义清理路径、清理白名单与空文件夹的清扫范围。规则按分组组织，可整组启停与排序。

除内置规则外，还可以订阅第三方**规则源**，添加后每天自动更新一次，在页面上呈现为一张独立卡片。发布规则源的方法见 [开发规则源](/guide/rule-source)。

### 应用缓存清理

按应用查看各条路径的实际占用并逐条增删；也可以从**云端共享库**拉取其他用户验证过的规则，或提交自己整理的规则等待审核。审核通过的规则会进入公开的规则快照，供所有用户获取。

### 回收站

按次查看清理记录（文件数、大小、过期时间），并将误删的文件一键恢复至原位。被清理的文件默认保留 7 天，保留期可通过 `general.recycle_keep_days` 调整。详见[功能详解 · 回收站与恢复](/guide/features#回收站与恢复)。

### 精细化压制

压制后台应用而不结束进程，运行状态完整保留、切回时即时恢复。该页会先探测设备的支持情况（系统版本、内核支持、当前开关状态与实际处于压制态的进程数），对应 `config.json` 的 `freezer` 一节。

另有**压制应用名单**页，逐个列出各应用的进程数、已压制数与内存占用，可按需勾选。

::: tip 与主页「后台压制」的区别
主页一键操作中的后台压制会直接结束进程；此处为挂起而不结束。详见[功能详解 · 精细化压制](/guide/features#精细化压制)。
:::

### 备份与恢复

将配置与全部规则导出为单个文件，换机或重新刷入后一键导回。

## 语言

CZeroX 支持 **简体中文** 与 **English**，跟随系统或在应用内切换。

## 与模块的关系

CZeroX 本身不执行清理，只负责**读写配置并展示状态**，实际的调度与清理由模块完成。因此即使不安装 CZeroX，模块也能按默认配置正常工作 —— 应用的价值在于让配置与查看变得直观。
